# Waffles Business Website

A responsive promotional website created for a technology-entrepreneurship project. It presents a waffle brand through product menus, company information, contact content, and a multi-post blog.

## Pages and content

- home landing page
- menu and product imagery
- about and contact pages
- blog index and individual posts
- responsive styling and Nicepage-generated front-end assets

## Tech stack

- HTML5 and CSS3
- JavaScript and jQuery
- Nicepage layout assets

## Run locally

The maintained site files are in `Waffles Website/`. Open `Waffles Website/index.html` directly, or serve that directory:

```bash
cd "Waffles Website"
python -m http.server 8000
```

Then visit `http://localhost:8000`.

The separate `Website/Pictures/` directory is retained as supporting source imagery from the coursework project.
